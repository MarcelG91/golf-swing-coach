# Glossar: Golfbegriffe Deutsch – Englisch

Teil von Kapitel 12 der Wissensseite. Viele Golfbegriffe sind auch im Deutschen englisch. Die Spalte
„Kapitel“ zeigt, wo der Begriff ausführlich erklärt wird. Rechtshänder: links = zielseitig.

## Schwung und Technik

| Deutsch | Englisch | Bedeutung | Kapitel |
|---|---|---|---|
| Ansprechen | Address / Set-up | Die Haltung am Ball vor dem Schwung (P1) | 2 |
| Rückschwung | Backswing | Bewegung vom Ball weg bis zum Top | 3 |
| Top | Top of backswing | Umkehrpunkt oben (P4) | 3 |
| Übergang | Transition | Wechsel vom Rück- in den Abschwung | 3 |
| Abschwung | Downswing | Vom Top bis zum Treffmoment | 3 |
| Treffmoment | Impact | Schläger trifft Ball (P7) | 3 |
| Durchschwung / Finish | Follow-through / Finish | Nach dem Treffen bis zur Endposition (P8–P10) | 3 |
| Vorneigung | Spine angle / Forward bend | Oberkörper aus der Hüfte nach vorn geneigt | 2 |
| Seitneigung | Side bend / Spine tilt | Oberkörper zur Seite geneigt (beim Ansprechen vom Ziel weg) | 2 |
| Seitliches Ausweichen | Sway / Slide | Hüfte schiebt seitlich statt zu drehen (Sway = im Rückschwung, Slide = im Abschwung) | 3, 8 |
| Aufrichten / Hüfte zum Ball | Early Extension | Hüfte schiebt im Abschwung Richtung Ball | 4, 8 |
| Kinematische Kette | Kinematic Sequence | Reihenfolge Becken → Brust → Arme → Schläger | 3 |
| Winkel halten | Lag | Winkel zwischen linkem Arm und Schaft im Abschwung | 3 |
| Frühes Auflösen | Casting / Flipping / Scooping | Handgelenkwinkel geht zu früh verloren, „Schaufeln“ | 3, 4 |
| Über den Ball kommen | Over the top | Abschwung startet mit Schultern → Bahn von außen | 4 |
| Schwungebene | Swing plane | Die Neigung, in der der Schläger kreist | 3 |
| Tempo / Rhythmus | Tempo / Rhythm | Verhältnis Rück- zu Abschwung (ca. 3 : 1) | 3 |
